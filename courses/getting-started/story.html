Welcome

How this learning portal works

This portal hosts interactive learning modules published from Articulate as self-contained HTML5 packages.

This short walkthrough is itself a module — it runs inside the portal's embedded player, exactly like a real Storyline or Rise export.

The Library

Finding a module

  • Browse the module library on the home page.
  • Filter by category — Basic Science, Diagnostics, Nerve Repair, and more.
  • Use search to match titles, descriptions, and tags.
  • Cards show level (Foundation / Intermediate / Advanced) and estimated duration.
The Player

Working through a module

  • Content plays in an embedded player — videos, slides, and quizzes behave exactly as designed in Articulate.
  • Use Fullscreen in the toolbar for distraction-free viewing.
  • When you finish, press Mark complete to record it.
Progress

Your progress is remembered

The library tracks which modules you have started and completed, and lets you continue or review at any time.

Progress is stored privately in your browser — no account needed.

That's it — press Library (top left) to explore.
